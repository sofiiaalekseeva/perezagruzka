## О проекте

**Перезагрузка** — минималистичный сайт о том, как замечать своё состояние и бережно к нему относиться. Он создан для преподавателей, но подойдёт любому, кто хочет лучше понимать себя: отметить настроение, проговорить мысли голосом, записать заметки, пройти тест или сыграть в карточную игру.

Это чистый **HTML + CSS + JavaScript** без сборки, фреймворков и серверов. Сайт открывается двойным кликом по `index.html` и без изменений работает на GitHub Pages.

## ✨ Возможности

| Раздел | Что можно делать |
| --- | --- |
| **Главная панель** | Отметить состояние дня, увидеть сводку (стресс, эмоциональный фон, энергия), кольцо недельной активности, серию дней подряд и график динамики за 7 дней |
| **Голосовой ассистент** | Записать голосовое сообщение с микрофона, прослушать и удалить записи |
| **Дневник** | Вести записи с отметкой настроения, просматривать и удалять их |
| **Тесты** | Проходить готовые тесты, получать расшифровку результата, создавать свои и выгружать их в код |
| **Карточная игра** | Сыграть в «Перезагрузку: сохрани свой ресурс» (значок карт рядом с вкладкой «Тесты») |
| **Личный кабинет** | Войти или зарегистрироваться (имя, логин, пароль) и посмотреть личную сводку |

Главная панель считается из ваших действий: настроение, записи, голосовые, тесты и игры влияют на графики и недельную активность.

## 📊 Тесты и расшифровка

Каждый ответ даётся по шкале от «Никогда» до «Всегда». Результат переводится в процент:

```
процент = (сумма баллов − число вопросов) / (4 × число вопросов) × 100
```

0% значит «Никогда» на все утверждения, 100% — «Всегда». Результат попадает в одну из четырёх зон (0–24, 25–49, 50–74, 75–100), а после теста сайт показывает:

- название уровня и описание того, как человек себя, скорее всего, чувствует;
- цветную шкалу с маркером результата;
- какие утверждения проявляются сильнее всего и какие почти не проявляются;
- 2–4 практических совета для своей зоны;
- динамику: сравнение с прошлым прохождением и последние результаты.

Встроенные тесты:

1. Экспресс-тест стресса
2. Шкала энергии
3. Что происходит с моей нагрузкой?
4. Уровень тревожности и напряжения
5. Мои сигналы усталости
6. Оценка моего ресурса
7. Мой прогресс и забота о себе

У каждого теста есть направление: «высокий процент — больше нагрузки» или «высокий процент — больше сил». От него зависят формулировки результата. Для тестов с утверждениями в разные стороны поддерживаются обратные пункты.

## 🃏 Карточная игра

Игра «Перезагрузка: сохрани свой ресурс» рассчитана на 1–2 человека и 20–30 минут. В колодах 40 карточек: по 10 в каждой из четырёх колод — **Ситуация, Осознание, Ресурс, Выбор**.

1. Оцените свой ресурс от 0 до 10.
2. Вытяните по одной карте из каждой колоды и выполните задания по порядку. Любую карту можно пропустить, к каждой можно написать заметку.
3. Снова оцените ресурс и запишите один шаг на ближайшие сутки.
4. Партия сохраняется в историю с оценкой «до → после».

Игра нужна для саморефлексии и профилактики. Она не является диагностическим тестом и не заменяет помощь психолога или врача.

## 🚀 Запуск

**Локально.** Скачайте репозиторий, откройте `index.html` в браузере. Больше ничего не нужно.

**На GitHub Pages.** В репозитории откройте *Settings → Pages*, выберите *Deploy from a branch*, ветку `main` и папку `/ (root)`. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/<название-репозитория>/`.

> Голосовые записи используют микрофон, поэтому браузер попросит разрешение. На GitHub Pages (HTTPS) это работает стабильнее, чем при открытии файла с диска.

## 🧩 Как добавить тест в код

Свои тесты, созданные на сайте, хранятся только в вашем браузере. Чтобы тест был у всех посетителей, добавьте его в массив `DEF` в начале файла `app.js`:

```js
{id:'my-test', title:'Название теста', own:0, dir:'load', r:[1,2], q:[
  'Первое утверждение',
  'Второе утверждение',
  'Третье утверждение'
]}
```

| Поле | Значение |
| --- | --- |
| `id` | уникальный идентификатор теста |
| `title` | название в списке тестов |
| `own` | `0` для встроенного теста (его нельзя удалить на сайте) |
| `dir` | `'load'` — высокий процент означает больше нагрузки, `'res'` — больше сил и ресурса |
| `r` | необязательно: номера вопросов (с нуля), которые считаются в обратную сторону |
| `q` | список утверждений |

Готовый код для уже созданных тестов можно получить кнопкой **«Выгрузить мои тесты в код»** в блоке «Добавить свой тест».

## 💾 Где хранятся данные

Всё хранится в `localStorage` вашего браузера: настроение, дневник, голосовые записи, результаты тестов, игры и профиль. Данные не уходят на сервер и не переносятся между браузерами и адресами. Страница с диска и страница на GitHub Pages для браузера считаются разными сайтами.

Вход в личный кабинет демонстрационный: подходят любые логин и пароль, пароль не проверяется и нигде не сохраняется.

## 🗂 Структура проекта

```
perezagruzka/
├── index.html   # разметка всех страниц и окон
├── style.css    # оформление, адаптивность, анимации
├── app.js       # логика: маршруты, дневник, голос, тесты, игра, кабинет

└── README.md
```

Страницы переключаются через хэш-адреса: `#home`, `#voice`, `#diary`, `#tests`, `#game`.

## 🛠 Технологии

- Чистые HTML, CSS и JavaScript, без зависимостей и сборки
- `MediaRecorder` API для голосовых записей
- SVG-графики и анимации на CSS
- `localStorage` для хранения данных
- Адаптивная вёрстка для компьютера и телефона
